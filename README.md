# 5.-Use-SDK-to-Automate-Static-Web-Hosting
AWS S3 static website hosting using Python (boto3)

## Project Overview
This project demonstrates how to automate static website hosting on AWS S3 using Python (boto3).

---

##  Objective
- Create S3 bucket using Python
- Upload website files automatically
- Enable static website hosting
- Make website publicly accessible

---

## 🧰 AWS Services Used
- Amazon S3
- IAM
- AWS CLI
- boto3 (Python SDK)

~ SDK = Software Development Kit
